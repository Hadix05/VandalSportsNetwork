**The Tech Stack**

- **Database:** MySQL running through XAMPP
- **Backend:** Python + FastAPI, run with `python -m uvicorn app:app --reload`
- **Frontend:** A single `index.html` file served through XAMPP's Apache server
- **Visualization:** Cytoscape.js (loaded from CDN, already implemented)
- **Data:** Kaggle NBA players CSV (`nba_players.csv`)

**Database Schema**

We have three tables. Run these SQL statements in phpMyAdmin to create them:

```sql
CREATE TABLE Nodes (
    NodeID INT AUTO_INCREMENT PRIMARY KEY,
    NodeType VARCHAR(50) NOT NULL,
    Name VARCHAR(100),
    Sport VARCHAR(50),
    Position VARCHAR(50),
    City VARCHAR(100),
    Tier INT
);

CREATE TABLE Edges (
    EdgeID INT AUTO_INCREMENT PRIMARY KEY,
    SourceNodeID INT NOT NULL,
    TargetNodeID INT NOT NULL,
    EdgeType VARCHAR(50) NOT NULL,
    StartYear INT,
    EndYear INT,
    FOREIGN KEY (SourceNodeID) REFERENCES Nodes(NodeID),
    FOREIGN KEY (TargetNodeID) REFERENCES Nodes(NodeID)
);

CREATE TABLE GraphMembership (
    GraphID INT NOT NULL,
    NodeID INT NOT NULL,
    GraphName VARCHAR(50),
    PRIMARY KEY (GraphID, NodeID),
    FOREIGN KEY (NodeID) REFERENCES Nodes(NodeID)
);

ALTER TABLE Nodes
ADD COLUMN pts FLOAT,
ADD COLUMN reb FLOAT,
ADD COLUMN ast FLOAT;
```

**What each table does:**
- **Nodes** stores every entity — players, teams, and leagues. Each node has a type, name, sport, and for players, stats (pts, reb, ast). The League node also has a Tier value (NBA = Tier 1).
- **Edges** stores relationships between nodes. EdgeType can be `plays_for` (Player → Team), `competes_in` (Team → League), or `teammate_of` (Player ↔ Player).
- **GraphMembership** maps nodes to graphs. GraphID 1 = NBA. This is how we support multiple sports as separate graphs.

---

**How the Database Was Populated**

I just used a Kaggle NBA players CSV (`nba_players.csv`) and a Python import script (`import_nba.py`) that reads the CSV and inserts everything into the database in one go. Here is what the script does when you run it:

1. Creates a League node for NBA with Tier = 1
2. For each unique player in the CSV, creates a Player node with their name, sport (NBA), and stats (pts, reb, ast from the CSV)
3. For each unique team abbreviation it encounters, creates a Team node and a `competes_in` edge connecting that team to the NBA league node
4. Creates a `plays_for` edge from the player to their team
5. Adds the player to GraphMembership under GraphID 1 (NBA)
6. Commits everything in a single transaction at the end

The script skips duplicate players (same player appearing in multiple seasons just gets one node for their first appearance in the CSV). The result is 2551 player nodes, 30 team nodes, 1 league node, and all corresponding edges.

**How to Get This Running on Your Computer**

**Step 1 — Pull the latest code from Git**

Open VS Code, open the project repo, and pull the latest changes. All the updated backend files (app.py, db_python.py, queries.py, import_nba.py) and the frontend (index.html) will be included.

**Step 2 — Start XAMPP**

Open the XAMPP Control Panel and start both **Apache** and **MySQL**. Both should turn green.

**Step 3 — Create the database in phpMyAdmin**

Go to `http://localhost/phpmyadmin` in your browser. On the left sidebar click **New**, name the database `sports-db`, and click Create. Then click the **SQL tab** and paste and run all the CREATE TABLE and ALTER TABLE statements listed above in the Database Schema section. Run them in the order listed.

**Step 4 — Install Python dependencies**

Open a terminal in VS Code and run:
```
python -m pip install mysql-connector-python fastapi uvicorn
```

**Step 5 — Run the import script**

In the terminal, navigate to the Backend folder:
```
cd C:\xampp\htdocs\CS3600_DataBase_Project\Backend
(this is my file structure for the project so thats why i specified cd into the write place, but if yours is differnt thats fine) 
C:/xampp/htdocs/CS3600_DataBase_Project/
    Backend/
        app.py
        db_python.py
        queries.py
        import_nba.py
        nba_players.csv
    Frontend/
        index.html
```
Then run:
```
python import_nba.py
```
Wait for it to print `Done! Imported 2551 players, 30 teams.` — this means the database is fully populated.

**Step 6 — Start the backend server**

In the same terminal run:
```
python -m uvicorn app:app --reload
```
Leave this terminal open and running.

**Step 7 — Open the frontend**

In your browser go to:
```
http://localhost/CS3600_DataBase_Project/Frontend/index.html
```
You should see the SportGraph DB interface with the Players page showing 2551 players loaded and the Teammate Network page working with Cytoscape.js visualization.
